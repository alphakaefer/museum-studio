Was daraus für ein Framework folgt

Ein Thema besteht aus drei austauschbaren Teilen: Design-Tokens (Farben, Schrift), einem Netzzeichner (Ranken, Raster, Git-Graph) und einer Stationsvorlage (Tafel, Plakat, Markdown-Datei). Die Daten bleiben gleich. Das lässt sich in der Seite als Thema-Schalter umsetzen.
