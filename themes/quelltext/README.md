# Skin „quelltext“

Idee: Computer-Code. Monospace-Stack, dunkel zuerst (GitHub-Dunkel-Anmutung), hell als Papier-Variante. Hero als Terminalfenster mit Prompt `$` und Blockcursor (nur bei erlaubter Bewegung blinkend),
Zeilennummern an den Reisekarten (CSS-Zähler), `//`-Kommentare für Eyebrows, `#`-Überschriften, `> `-Zitate, `[1]`-Fakten, `git merge` für Umsteigen. Syntax-Tokens `--sx-key --sx-str --sx-num --sx-cm --sx-kw`.
Netzplan: `octilinear` / `shapes`.

Grenzen: Echte Hash-Kennungen sind per reinem CSS nicht möglich (nur Zähler). Monospace verbreitert Texte; Absätze sind deshalb auf 44rem begrenzt. Der Reisepass-Deckel bleibt dunkel.
JetBrains Mono ist nicht eingebettet; Rückfall auf Menlo/Consolas/DejaVu Sans Mono.
