# Skin „ma“

Idee: Weißraum, Raster, Grotesk (Jost/Futura/Century Gothic/System), kräftige Primärakzente (Rot, Blau, Gelb), große Zahlen, flache Flächen ohne Schatten und Rundungen, asymmetrischer Eingang
(kleingeschriebener Titel, roter Kreis). Netzplan: `octilinear` / `shapes`.

Tokens: wie die Engine plus `--ma-red --ma-blue --ma-yellow`; `--radius*: 0`, `--shadow*: none`, `--grain: none`. Journey-Farben unverändert.

Grenzen: Der Titel im Eingang wird per CSS kleingeschrieben (nur Hero und Markenname, nie Stationstitel). Ansichts-Module (Karte, Zeitstrahl, Pass, Suche) erhalten nur Tokens und wenige eckige Rahmen.
Der Reisepass-Deckel ist wie in der Engine immer dunkel. Futura/Jost sind nicht eingebettet; Rückfall auf Systemschrift.
